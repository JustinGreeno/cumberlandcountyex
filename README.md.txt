# Cumberland County Exhibition Website

A production website built for the Cumberland County Exhibition in Nova Scotia, Canada.

## About

Designed, developed, and deployed for a real client. The site serves as the public-facing web presence for the Cumberland County Exhibition, providing event information, schedules, and community resources.

## Status

Live in production. Ongoing maintenance contract active.

## Built With

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Features

- Mobile-friendly responsive layout
- Event and schedule information
- Community-focused design
- Ongoing updates and maintenance
